# Prospective External Validation of Composition-Based Peroxidase-like Nanozyme Kmapp Models

This repository contains the curated data, analysis code, split manifests,
metrics, configuration files, and automated tests accompanying the manuscript:

**Prospective External Validation of Composition-Based Peroxidase-like Nanozyme
Kmapp Models: No Detectable Advantage over a Substrate-Median Baseline**

## Study overview

The study evaluates whether composition-based models trained on pre-2024
peroxidase-like nanozyme kinetics provide measurable predictive benefit on a
separately curated 2024–2026 external corpus.

The primary endpoint is:

`log10(Kmapp / M)`

The repository supports:

- deterministic internal-data curation;
- random, source, formula, composition-cluster, and component holdout;
- CatBoost, ExtraTrees, ElasticNet, and median baselines;
- prospective external validation;
- shared-schema validation;
- conformal uncertainty analysis;
- sensitivity and robustness controls.

## Data

The `data/` directory contains:

- `internal_modeling_curated_992.csv`: curated internal modeling cohort;
- `internal_shared_schema_915.csv`: internal TMB–H2O2 shared-schema cohort;
- `external_validation_curated_322.csv`: author-curated external validation set;
- `internal_curation_filter_log.csv`: deterministic internal filtering log.

The external corpus contains 322 substrate-specific records from 127
publications. DOI and bibliographic metadata are used for provenance and
independence auditing, not as model features.

## Repository structure

- `src/`: reusable data, feature, split, model, evaluation, and conformal code;
- `scripts/`: analysis entry points and sensitivity analyses;
- `tests/`: automated software tests;
- `configs/`: fixed analysis configuration;
- `data/`: curated analysis tables;
- `reproducibility/splits/`: archived split assignments and split metadata;
- `results/metrics/`: archived benchmark and conformal metrics.

Generated tables and figures are not stored in the repository. They are
regenerated by the analysis scripts.

## Software environment

The manuscript analysis was run with Python 3.12.10.

Install the pinned dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt

pytest -q

python scripts/run_all.py \
  --data data/internal_modeling_curated_992.csv \
  --quick

python scripts/run_all.py \
  --data data/internal_modeling_curated_992.csv

python scripts/run_external_validation.py \
  --train-data data/internal_modeling_curated_992.csv \
  --external-data data/external_validation_curated_322.csv

python scripts/run_restricted_feature_validation.py \
  --train-data data/internal_modeling_curated_992.csv \
